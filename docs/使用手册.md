# TokenScope 使用手册

本文档说明 TokenScope 的界面功能与使用方式。适用于统计 Hermes / Codex / Claude Code / zcode 四个 AI 编码工具的 token 消耗与成本。

- 项目主页：见 [README](../README.md)
- 安装部署：见 [安装手册](安装手册.md)

## 界面总览

页面左侧为导航栏（仪表盘 / 会话明细 / 数据源 / 定价设置），顶部为全局筛选（工具 + 时间范围），下方为内容区。

## 1. 全局筛选

顶部工具栏可对**所有视图**生效：

- **工具下拉**：全部工具 / Hermes / Codex / Claude Code / zcode。选择后，仪表盘与会话明细只统计该工具的会话。
- **时间范围**：近 7 天 / 近 30 天 / 近 90 天 / 全部 / 自定义（自定义可选择起止日期）。

切换筛选后各视图自动刷新，无需手动操作。

## 2. 仪表盘

### 2.1 统计卡片（8 张）

| 卡片 | 说明 |
|---|---|
| 输入 Tokens | 全部输入 token 总量（含未命中缓存的输入） |
| 输出 Tokens | 模型输出 token 总量 |
| 缓存读取 | 命中缓存的输入 token 量（通常远大于输入，属正常现象） |
| 推理 Tokens | 推理类模型的思考 token 量 |
| 估算成本 | 按定价表估算的总成本；未配置定价的模型成本显示「—」 |
| API 调用 | 模型请求总次数 |
| 总 Token 消耗 | 输入 + 输出 + 缓存读取 |
| 输出 / 输入比 | 输出与输入比例 + 平均每会话 token 量 |

### 2.2 图表

- **Token 消耗趋势**：按天 / 周 / 月粒度，柱状（输入/输出/推理）+ 折线（缓存读取，右轴）
- **按模型**：各模型输入/输出横向柱状
- **按工具**：四工具占比环形图
- **按来源**：桌面端 / VS Code / 终端 / 子代理等占比环形图
- **按任务类型**：主对话 / 审批 / 标题生成 / 子代理等调用次数占比（Hermes 会话的任务级数据）

### 2.3 模型明细表

每个模型的会话数、调用次数、输入 / 输出 / 缓存读取 / 推理 tokens 与估算成本。成本列为「—」表示该模型未配置定价。

## 3. 会话明细

### 3.1 筛选与搜索

- 搜索框：匹配标题、会话 ID、模型名、工具名、工作目录（支持中文）
- 模型下拉、来源下拉：进一步缩小范围
- 顶部工具下拉与时间范围同样生效

### 3.2 表格

| 列 | 说明 |
|---|---|
| 标题 | 带工具彩色标签（Hermes 蓝 / Codex 紫 / Claude Code 橙 / zcode 青） |
| 模型 / 来源 / 消息 / 调用 | 基础信息 |
| 输入 / 输出 / 缓存读 / 推理 | 各 token 维度，点击表头可排序 |
| 成本 | 估算成本（排序可用） |
| 开始时间 / 时长 | 会话时间信息 |

### 3.3 会话详情

点击任意行打开右侧详情抽屉：

- 会话标题、工作目录（Codex / Claude / zcode 会话显示项目路径）
- 会话 ID、模型、来源、开始时间、消息数、工具调用数
- 四张 token 卡片：输入 / 输出 / 缓存读取 / 推理
- **按任务拆分**：Hermes 会话显示任务级明细（主对话 / 标题生成 / 审批 / 子代理等）；其他工具显示提示「暂无任务级拆分，明细为工具汇总值」

## 4. 数据源

「数据源」页面展示所有已接入的数据源：

- **状态点**：绿色 = 可读，红色 = 文件缺失
- **类型标签**：Hermes / Codex / Claude Code / zcode
- **统计**：会话数、输入、缓存读取、数据库大小、最后活动时间
- **自动发现**：启动时自动扫描四工具的默认位置，无需配置
- **手动添加**：支持添加其他路径的数据（如其他机器拷贝的数据库文件）。选择数据类型（默认 Hermes），填写路径（Claude 类型填项目目录，其余填数据库文件或所在目录）
- **移除**：仅手动添加的源可移除（两段式确认，3 秒内再次点击生效）；自动发现的源不可移除
- **刷新统计**：数据源数据变化后点击刷新重新统计

> 所有数据源**只读**访问，TokenScope 不会修改任何工具的数据。

## 5. 定价设置

用于成本估算的模型定价表：

- 单价单位：**USD / 每百万 tokens**（输入 / 输出 / 缓存读取 / 缓存写入四档）
- 编辑：修改数字后点击「保存」，各页面成本立即重新估算
- 添加模型：点击「添加模型」新增一行
- 删除模型：行末垃圾桶图标
- **填充示例定价**：一键写入 DeepSeek / GPT / Claude / GLM / Qwen 官方参考价（覆盖当前定价，需确认）

成本公式：`输入 ÷ 1e6 × 输入单价 + 输出 ÷ 1e6 × 输出单价 + 缓存读取 ÷ 1e6 × 缓存读取单价`

> 模型名匹配不区分大小写（如 `GLM-5.2` 与 `glm-5.2` 视为同一模型）。未配置定价的模型，成本一律显示「—」。

## 6. 数据口径说明

| 工具 | 明细粒度 | 说明 |
|---|---|---|
| Hermes | 会话级 + 任务级 | sessions 表全维度；session_model_usage 提供任务拆分 |
| Codex | 会话级 | threads 表索引 + rollout JSONL 的 token_count 事件（input 含缓存命中量） |
| Claude Code | 会话级 | 逐条 assistant 消息 usage 累加；cache_write 对应 cache_creation |
| zcode | 会话级（源为请求级） | model_usage 表按会话聚合，数据最精确 |

- **缓存读取**通常远大于输入：长会话中历史上下文大量命中缓存，属正常现象（各家 API 缓存价格通常仅为输入价的 1/10）。
- **Codex 模型名**读取自 `~\.codex\config.toml` 的 `model` 配置；如临时切换过模型，历史会话按当前配置模型统计。

## 7. 常见问题

**Q1：成本估算准确吗？**
估算基于定价表中的单价，请按实际采购价（API 官网价或渠道价）配置。缓存读取价通常是输入价的 10% 左右，可参考示例定价。

**Q2：数据多久更新一次？**
每次请求页面时自动读取最新数据（带内存缓存，文件变化后自动失效）。点「刷新数据」可强制刷新。

**Q3：能看到每个消息的 token 吗？**
当前版本按会话维度统计；Hermes 会话可下钻到任务（主对话 / 审批 / 子代理等）。如需消息级明细可反馈需求。

**Q4：能把统计结果导出吗？**
当前版本未提供导出功能，可反馈需求（如 CSV 导出 / 日报周报）。
